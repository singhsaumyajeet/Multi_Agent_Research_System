# 🔍 Multi-Agent Research System

An AI-powered research assistant that transforms a simple user query into a comprehensive, well-structured, and professionally reviewed research report.

## ✨ Features

* 🌐 Searches the web for relevant information
* 📅 Collects recent and up-to-date content
* 📄 Extracts and processes information from multiple sources
* 🤖 Uses multiple specialized AI agents for research, analysis, writing, and review
* 📝 Generates detailed and polished reports automatically
* ✅ Reviews and scores report quality before final delivery

## 🏗️ Workflow

```text
User Query
    ↓
Research Agent
    ↓
Search Agent
    ↓
Content Extraction Agent
    ↓
Analysis Agent
    ↓
Report Writer Agent
    ↓
Review & Scoring Agent
    ↓
Final Research Report
```

## 🚀 Example Query

```text
Analyze the impact of Generative AI on Software Development
```
